# Moonshot: a shared natural-history study for Krabbe

Draft for review by Recep and Hanno. 2026-10-04, Europe/Vienna. No measured acceleration claim is available.

## Milestone

A patient group and qualified researchers produce a reviewed proposal for a shared Krabbe natural-history study, reusing suitable existing registries and study methods, including lessons from MLD. Study approval, recruitment and follow-up remain separate downstream milestones. A similar mechanism does not make a treatment transferable.

## Comparison to measure

| Manual route | Constellate route | Same completion criterion |
|---|---|---|
| Search databases and organization sites, compare studies, record sources and unresolved questions | Follow the mapped disease and study links, inspect evidence, assemble an Action Card | An independently reviewed proposal with an existing-study inventory, candidate partner, justified reusable elements, differences, citations and unresolved questions |

Measure active researcher time separately from elapsed calendar time. Use matched tasks, the same data cutoff and the same review rubric. Include correction time and rejected proposals. Record participants' prior knowledge and balance task order to limit learning effects. Freeze the success criterion before timing either route.

Acceleration = median active time for the manual route / median active time for the Constellate route, only for proposals that meet the same quality threshold. No baseline duration, Constellate duration or observed factor has been measured here.

## Assumptions to test

- Existing data and protocol materials are accessible and may be reused with permission.
- Patient groups and researchers are willing to collaborate.
- Researchers judge the proposed endpoints and methods appropriate for Krabbe.
- Source checks and corrections preserve proposal quality in both routes.
- Navigation time is a meaningful bottleneck; ethics review, consent, funding and longitudinal follow-up cannot be assumed to shrink with search time.
